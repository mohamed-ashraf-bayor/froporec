Froporec

Compile-time processor that transforms your POJOs into deeply-immutable Java Records, ships handy factory methods, and even lets you “extend” final records – no boilerplate, no runtime cost.

Maven Central 1.4 GitHub 
@Record
class Person {
  String name;
  int age;
  // ...
}

Person jane = new Person("Jane", 28); // all-args constructor assumed

// PersonRecord is generated at compile-time
author
PersonRecord janeRecord = new PersonRecord(jane);

// Create a new record from existing
PersonRecord youngerJane = jane.with("age", 12);

Why developers ❤️ Froporec

⚡️

Zero runtime cost

Pure compile-time APT – no agents, no reflection, no surprises.

🛡️

Deep immutability

Generated records recursively copy collections & nested POJOs for true thread-safety.

🚀

Turbo productivity

Factory builders, field constants & record “extension” cut boilerplate.

Get started

Maven 
<dependency>
  <groupId>org.froporec</groupId>
  <artifactId>froporec</artifactId>
  <version>1.4</version>
</dependency>
Gradle (Kotlin DSL) 
dependencies {
  annotationProcessor("org.froporec:froporec:1.4")
  compileOnly("org.froporec:froporec:1.4")
}
